# M-SPACE 8차 회의 정리 (멘토 점검: 시연 뒤 피드백)

Nov 6, 2026 · @나영준 · 녹취(음성 인식, 약 22분) 정리

> **참석자 표기:** 녹취에는 "참석자 1~9"로만 나온다. 이름은 추정하지 않고 역할로만 적는다. **멘토**(참석자 1·5, 점검과 아이디어 제안), **팀**(나머지, 시연·질문). 누가 어느 팀원인지는 적지 않는다.
> 음성 인식 오타는 고쳐 적었다: 엠스페이스·N스페이스 → M-SPACE, 루미 → 룸(방), 계약 → 예약, 비밀법 → 비밀번호(입실 번호), 음송·운송 → 음성, 자절자절 → 재잘재잘, 능조형 → 능동형, 대소의 성향 → 비서의 성향, 이산화상 → 이산화탄소(CO2), 이상수 탐지 → 이상 탐지, 제스틴보드 → 젯슨 보드, PRS → PIR, 훈련 작성 → (이력서·포트폴리오) 작성.
> 회의 날짜는 녹취를 받은 날(11/6, 금) 기준이다(확인 필요). 앞부분 1분(다른 팀 4컷 만화 아이템 이야기)은 우리 프로젝트와 관계없어 뺐다.

## 멘토 피드백 자세히

### 1. AI 기능: 능동형 비서와 음성

- 예약만 하는 기능은 요즘 앱이면 다 된다. "4명이서 3시 이후 회의실 예약" 같은 건 새로워 보이지 않는다
- **비서가 주인을 시키는** 그림: 드라마 속 비서처럼 옆에 붙어 재잘재잘. 수동적인 학생을 움직이게 한다
- 성향 선택: 혈액형처럼 "수동형 / 조금 능동형 / 아주 능동형". 성향에 따라 잔소리 양이 달라진다 (팀 반응: 비서 성격 고르기가 재미있겠다)
- 음성: "집에 가서 텍스트 치지 않는다. 걸어 다니면서 말로 시킨다." 관리자도 음성으로 현재 이용 현황을 들을 수 있게
- 아이디어는 100가지를 생각해야 1~2가지가 나온다. 말도 안 되는 것도 서로 던져 보고, 만들어 보고, 실패도 해 봐야 나온다

### 2. 범위: M-SPACE 안으로

- 학교 공지·학사 시간표를 넣는 순간 **학교 전체 일정 서비스**로 바뀐다. 너무 많이 넣을 필요 없다
- M-SPACE라는 **공간을 관리하는 일**에 집중: 사용자 관점과 관리자 관점 두 가지로 "무엇이 필요한가"를 계속 묻는다

### 3. 관리자 관점

| 지표 | 왜 |
| --- | --- |
| 이용률 | 방이 실제로 얼마나 쓰이는지 |
| 예약 대비 실제 사용 | 예약하고 진짜 썼는지(노쇼) |
| 이용자 구성 | 누가 주로 쓰는지 |
| 평균 이용 시간 | 3–5시 잡고 10분만 쓰고 가는 경우 → 효율이 나쁨 |
| 재실 인원 | 몇 명이 쓰는지 |
| 시설 상태 | 깨끗하게 관리되는지, 환기가 되는지, 이상한 일이 없는지(이상 탐지) |

### 4. 센서와 카메라

- 레이저 센서로 인원을 셀 수 있는지는 "해 봐야 안다"(팀). 지금 계획은 "방에 사람이 있다/없다"까지
- PIR은 가만히 있으면 감지를 못 한다 → 자고 있으면 "없음"으로 쳐 버린다
- 받은 카메라로 몇 명 있는지 셀 수 있다. **레이저 센서를 따로 살 필요 없다**
- 멘토가 가진 센서(입출입, 자리 착석, CO2·온도·습도·소음·조도 통합)를 필요하면 가져올 수 있다
- 카메라 우려(얼굴)에 대한 답: 사진을 찍더라도 **몇 명인지만** 쓰게 만들면 된다. 회사 사무실처럼 설치는 운영 쪽 결정이다. 젯슨 보드와 AI를 활용했다는 의미도 있다
- 응용: 어린이집(아이가 구역을 벗어남), 펫 카페(특정 공간 이상 상황), 요양원 **낙상 감지**(센서는 부정확, 카메라가 가장 정확). "단순한 학교 시스템이지만 이렇게 응용할 수 있다"고 포트폴리오에서 넓힐 수 있다
- 회의 중 쓰러짐 같은 상황을 바로 판단하는 것도 같은 기술로 가능하다는 언급

### 5. 환경 센서로 사용자에게 말 걸기

- 좁은 방에 여럿이 모이면 CO2가 금방 오른다 → "환기해 주세요", "머리가 안 돌아가니 쉬었다 하세요"
- 너무 더우면 에어컨을 켜라고 안내(직접 켜지는 않더라도)

### 6. 하드웨어와 시연

- 입실은 NFC나 폰으로. 장치를 최소로
- 아크릴 박스에 넣어 깔끔하게. 센서는 박스 위, 선은 안으로. 외관 디자인도 AI로 해 볼 수 있다
- 비용(팀 질문): 지원 없음. 방 하나만 시제품으로 만들면 된다. 실제 운영 단계에서 고민하면 되고, 상금으로도
