## 재웅: 시간표 비서 기능 기획서 (회의용 초안)

비서 스페이시가 학생 시간표를 알고 "오늘 수업 끝나고 30분 뒤 빈방 잡아 줘"를 한 번에 처리하게 하는 안. 요구사항 FR-AGT-102를 102a–d로 나눈 초안을 [요구사항 명세](../requirements/requirements.md) 8장에 넣었다(상태: 초안).

| 장면 | 학생 말 | 쓰는 도구 |
| --- | --- | --- |
| A. 오늘 스케줄 | "오늘 스케줄 어떻게 돼?" | `my_schedule`, `my_reservations` |
| B. 수업 끝나고 빈방 (시연 후보) | "수업 끝나고 공부할래. 남는 방 몇 개야?" | `my_schedule` → `find_available_rooms` → `create_reservation`(확인 카드) |
| C. 없으면 내일 | "오늘 수업 끝나고 30분 뒤에 방 있으면 예약해. 없으면 내일 수업 끝난 뒤로" | 위와 같음 + 날짜 바꿔 한 번 더 |

**다음 회의에서 정할 것** (기획서 추천안)

| # | 정할 것 | 추천안 |
| --- | --- | --- |
| 1 | FR-AGT-102를 v0.3에 넣을지 | 1단계(장면 A·B)만. 새 도구는 `my_schedule` 1개 |
| 2 | 시간표 저장 위치 (요구사항 Q-15) | core 테이블 1개 + `GET·PUT /api/me/schedule`. 지영 시간이 없으면 비서 Redis(영준 의견) 또는 시연용 브라우저 저장 |
| 3 | 끝 + 여유와 칸 올림 | 여유 30분 설정값, 다음 30분 칸으로 올림 |
| 4 | 시연 모델 | 시연 Claude(재웅 크레딧), 대체 Gemini. 팀 결정 전 |
| 5 | 음성 브리핑 | 발표 뒤. 발표에서는 그림으로만. 홈 카드 [듣기] 버튼 |
| 6 | 학기 끝 시간표 지우기 | 학생 직접 지우기 + 학기 끝 자동 삭제 |
