| 처음 보는 방이면요? | 원래 있던 물건인지 새로 생긴 건지 모르니 정확도가 떨어집니다. 그래서 공간을 등록할 때 빈 방 기준 사진을 찍어 두고, 퇴실 뒤 사진을 그것과 비교합니다. |
| **왜 젯슨을 썼나요?** (멘토 11/13) | 학교에서 받은 장비 중 AI 모델을 돌릴 수 있는 게 젯슨뿐이었습니다. 젯슨은 공장처럼 그 자리에서 바로 판단해야 할 때 쓰는 장비인데, 저희 일은 퇴실 뒤 몇 초 늦어도 됩니다. 그래서 판단은 서버 한 대가 모아서 하고, 시제품에서는 젯슨이 그 서버 역할을 합니다. 학교에 들일 때는 학교 서버 GPU 한 장으로 바꾸면 됩니다(슬라이드 21, 비용 분석 4.4). |
| **레이더 센서는 왜 안 썼나요?** | 처음엔 PIR이 가만히 앉은 사람을 놓쳐서 레이더 재실 센서를 주문했습니다. 그런데 8차 멘토 점검(11/6)에서 "이미 받은 카메라로 세 보라, 따로 살 필요 없다"는 조언을 받아 환불했습니다. 재실은 PIR·조도·CO2 규칙으로 판단하고, 카메라는 레이더가 못 하는 두고 간 물건 확인에 씁니다. 감지 부분은 인터페이스라 레이더를 다시 끼울 수 있습니다. `[확인: 수연, 산 값·환불 여부]` |
| **모델을 학습시켰나요? 그냥 갖다 쓴 것 아닌가요?** | 학습은 하지 않았습니다. GPU와 데이터가 없어서이고, 저희가 풀려던 문제는 새 모델이 아니라 틀려도 안전한 서비스였습니다. 대신 정확도를 올린 시도를 기록했습니다. 11/11 51%에서 시작해 의자 위를 한 번 더 보게 하는 식으로 89.7%까지 올렸습니다 `[채울 칸: 수연, 단계별 무엇을 바꿔 몇 %]`. 놓침과 오판이 같이 안 줄어서, 마지막엔 경고를 빼 틀려도 피해가 없게 설계를 바꿨습니다. 비서도 같은 방식으로 89.8 → 98.5점입니다. |
| 젯슨 메모리는 충분한가요? | 8GB 중 약 5.7GB를 씁니다. 더 큰 VLM은 지금 모델을 끄고 바꿔야 해서 시험 중입니다. |
| 작은 물건(이어폰)은요? | 줄 이어폰처럼 작은 건 원본 해상도로도 못 찾았습니다. 한계로 밝힙니다. |
| YOLO 라이선스 문제는요? | YOLO는 AGPL-3.0이라 교내 시범과 오픈소스 배포는 됩니다. 유료로 팔 때는 코드 공개, 유료 라이선스, 다른 모델 교체 중 하나를 고릅니다. |
| QR 입실은 어떻게 동작하나요? 사진을 찍어 남이 쓰면요? | `[채울 칸: 수연, QR 안 내용·유효 시간·실패 잠금]` 입실 번호는 예약마다 다르고 시작 10분 전부터 종료 전까지만 유효합니다. 5번 틀리면 1분 잠깁니다. |
| 재실은 어떻게 판단하나요? | PIR·조도·CO2 센서 규칙으로 판단하고, 애매하면 "사람 있음" 쪽으로 판단해 잘못 쫓아내지 않게 했습니다. |
